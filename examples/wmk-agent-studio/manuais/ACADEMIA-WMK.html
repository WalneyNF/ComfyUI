Módulo 1 — Primeiros passos (usuário comum)

O que é? O WMK Agent Studio é um aplicativo local acessado pelo navegador. Um agente é uma configuração de instruções (especialidade e comportamento). O modelo de linguagem é quem interpreta e responde. O provedor é o serviço que executa esse modelo. O ComfyUI é um programa separado que gera imagens.

  1. Execute INICIAR-WMK.bat na pasta do projeto ou python server.py.
  2. Abra http://127.0.0.1:8765 no mesmo computador.
  3. Entre em Provedores e modelos e confirme o provedor configurado.
  4. Escolha o agente e o modelo na barra superior do chat.
  5. Digite uma pergunta simples: Explique o que é um workflow em três exemplos.
  6. Se o modelo não responder, verifique se Ollama está ativo ou se a API remota está configurada.

Módulo 2 — Geração de imagens

Existem dois caminhos: clicar em Gerar imagem e preencher o formulário, ou pedir ao agente para criar uma imagem. No segundo caso, o agente deve apresentar uma proposta de ferramenta para aprovação. O envio ao ComfyUI ocorre apenas depois da autorização.

  1. Inicie o ComfyUI local na porta 8188.
  2. Confira se o checkpoint v1-5-pruned-emaonly.safetensors está instalado.
  3. No chat, peça: Crie um guerreiro medieval em pixel art com armadura negra e espada flamejante.
  4. Inspecione o cartão Gerar imagem e clique em Ver grafo / plano.
  5. Depois de revisar, clique em Autorizar geração se desejar realmente executar.
  6. Acompanhe o status; gerar em CPU pode levar muito tempo.
Limitações importantes: 256 × 256 e poucos steps servem para testar a integração, não garantem boa arte. Mais steps não asseguram qualidade. O checkpoint SD 1.5 genérico não é especializado em pixel art. CPU sem GPU compatível pode ser extremamente lenta; não inicie várias gerações simultâneas.

Exemplo de prompt

Full-body medieval dark knight, black plate armor,
flaming enchanted sword, clean 16-bit RPG pixel art,
readable silhouette, detailed sprite, dark fantasy,
controlled palette, dramatic contrast

Prompt negativo: blurry, watermark, text, distorted anatomy, low quality. O efeito depende do checkpoint e dos parâmetros.

Módulo 3 — Aprender o grafo do ComfyUI

O grafo é um fluxo de operações: cada caixa é um nó e cada linha indica que a saída de um nó alimenta a entrada de outro. Na versão atual do WMK, a visualização é simplificada e mostra o plano usado pela integração, não o editor nativo completo.

                        └─→ VAEDecode (VAE)     │
EmptyLatentImage ───────────→ KSampler ←────────┘

                                ▼
                            VAEDecode
                                │
                                ▼
                             SaveImage
NóFunçãoO que alterar
CheckpointLoaderSimpleCarrega modelo, CLIP e VAE.Checkpoint compatível.
CLIPTextEncode positivoConverte descrição desejada em condicionamento.Prompt positivo.
CLIPTextEncode negativoConverte características indesejadas em condicionamento.Prompt negativo.
EmptyLatentImageCria o latente inicial com tamanho definido.Largura, altura e lote.

Como testar a exportação

  1. No formulário de imagem, clique em Ver grafo antes de gerar.
  2. Revise as caixas e linhas.
  3. Clique em Salvar workflow JSON (API).
  4. Abra o JSON num editor de texto e procure class_type, inputs e as conexões como ["5",0].

Dois formatos de JSON

Workflow UI

Exportado pelo editor visual do ComfyUI. Costuma conter nodes, links, posições e configurações de interface. É adequado para reabrir e editar visualmente.

Workflow API

Mapa de IDs para objetos com class_type e inputs. É adequado para enviar ao endpoint POST /prompt do ComfyUI.

{
  "4": {
    "class_type": "EmptyLatentImage",
    "inputs": {"width": 256, "height": 256, "batch_size": 1}
  }
}

O arquivo exportado pela prévia usa seed fixa 42 como referência; a geração efetiva no WMK pode usar seed aleatória. Portanto, o arquivo de exemplo não representa necessariamente os parâmetros exatos de uma execução já realizada.

Exemplo de chamada local

curl http://127.0.0.1:8765/api/health

Fluxo de aprovação

Usuário solicita imagem
  → LLM propõe gerar_imagem (ou fallback)
  → Servidor registra tool_request pendente
  → Chat apresenta cartão e grafo
  → Usuário aprova ou rejeita
  → Se aprovado: ComfyUI recebe workflow
  → Consulta /history/{prompt_id}
  → Chat apresenta imagem / status

Tool calling não é MCP: o agente pode propor a função gerar_imagem, mas o executor atual chama diretamente a API HTTP do ComfyUI. Isso não constitui, por si só, um servidor MCP.

Como acrescentar novos nós

  1. Crie e valide um workflow no ComfyUI.
  2. Exporte o formato API para execução e o formato UI para edição.
  3. Verifique IDs, class_type, entradas obrigatórias e conexões.
  4. Implemente o suporte no gerador de workflow do servidor.
  5. Atualize o visualizador em web/app.js, que hoje representa um pipeline fixo de sete nós.
  6. Adicione testes de validação antes de permitir execução e preserve uma cópia funcional.

Catálogo de exemplos

Os exemplos encontrados em D:\IA-local\ComfyUI\samples\json foram catalogados em data/workflow_catalog.json. Atualmente esse arquivo é um inventário de referência; os agentes ainda não selecionam e executam automaticamente os workflows catalogados.

Segurança e manutenção

  • Mantenha o servidor limitado a 127.0.0.1; não publique a porta diretamente na internet.
  • Não inclua chaves de API em exportações ou repositórios públicos.
  • Valide prompts, tamanhos, caminhos, formatos e IDs no backend.
  • Confirme ações que consomem CPU, tempo ou serviços pagos.
  • Faça backup de data/studio.json antes de alterações estruturais.
  • Não execute automaticamente workflows externos sem revisar nós personalizados e dependências.

Módulo 5 — Diagnóstico e solução de problemas

O agente mostrou JSON com name/arguments em vez de cartão

Alguns modelos pequenos reproduzem a definição da ferramenta como texto. Atualize a página com Ctrl+F5, use uma conversa nova e solicite explicitamente uma imagem. Se persistir, inspecione a resposta do endpoint /api/agent-chat e verifique se há tool_request e tool_request_id.

O botão Ver grafo não aparece

Verifique o cache do navegador e se /app.js é servido corretamente. O botão aparece no cartão da proposta e no formulário manual de imagem, não em qualquer resposta textual.

ComfyUI não responde

Confirme http://127.0.0.1:8188, checkpoint instalado, console do ComfyUI e fila de execução. Não confunda serviço disponível com geração concluída.

A imagem ficou ruim

Verifique checkpoint, prompt, resolução, steps, CFG e sampler. Testes em 256 px com poucos steps não equivalem a um preset de qualidade. Pixel art pode exigir modelo específico ou pós-processamento.

O workflow JSON não abre no editor visual

Provavelmente é JSON API. Para edição no canvas do ComfyUI, use um workflow exportado no formato UI. A conversão exige mapear também posições, links e metadados.

Por que a CPU demora?

Difusão executa muitas operações matriciais. Sem GPU compatível, o tempo cresce com resolução, steps, modelo e carga do sistema. Não existe tempo fixo garantido.

Módulo 6 — Exercícios práticos

Iniciante

  1. Abra o WMK e selecione um agente.
  2. Crie uma conversa e peça uma imagem.
  3. Abra o grafo, identifique os sete nós.
  4. Exporte o JSON e localize o prompt.

Intermediário

  1. Compare Euler e DPM++ 2M dos exemplos salvos.
  2. Explique o papel de steps, CFG e seed.
  3. Altere o prompt no JSON exportado.
  4. Identifique as entradas do KSampler.

Avançado

  1. Desenhe o contrato de uma ferramenta gerar_imagem.
  2. Valide parâmetros antes de chamar o ComfyUI.
  3. Crie testes para aprovação/rejeição.
  4. Planeje um importador seguro de workflows UI/API.

Perguntas para verificar seu entendimento

  1. Quem produz a imagem: Ollama ou ComfyUI?
  2. Qual a diferença entre prompt positivo e negativo?
  3. Por que o grafo tem ligações entre nós?
  4. Por que salvar JSON não é o mesmo que treinar um modelo?
  5. O que acontece se você rejeitar a proposta de ferramenta?

Respostas: ComfyUI; condicionamentos desejado/indesejado; fluxo de dados; JSON guarda instruções/configurações, não modifica pesos; a geração não deve ser executada.

Atualização: ponte Chat → ComfyUI e qualidade

O texto digitado no chat é interpretado pelo agente. O cartão de geração agora permite editar PROMPT POSITIVO, PROMPT NEGATIVO, RESOLUÇÃO, STEPS, CFG e SAMPLER antes da aprovação. O servidor valida os parâmetros e envia um workflow API JSON ao ComfyUI. No grafo, o nó 2 recebe o prompt positivo e o nó 3 recebe o negativo; ambos alimentam o KSampler. O nó 4 define a resolução. O nó 5 usa steps, CFG e sampler. O nó 7 salva o PNG.

Para melhorar: experimente 384 x 384, 20 steps, CFG 7 e sampler Euler ou DPM++ 2M. 512 x 512 e 25-30 steps são mais lentos na CPU. Um checkpoint SD 1.5 genérico pode não produzir boa pixel art mesmo com mais passos. O agente nem sempre gera um prompt detalhado; revise e melhore o texto antes de aprovar.

O grafo exportado contém uma seed fixa 42 para demonstração; a geração usa seed aleatória. Imagens PNG ficam em D:\IA-Local\ComfyUI\output e podem ser baixadas pelo chat.
