WMK Agent Studio

Como usar

1. Abra Provedores e modelos, escolha Ollama ou configure sua chave Groq.

2. Atualize a lista de modelos disponíveis. Para Ollama, o serviço precisa estar ativo na porta 11434.

3. Crie agentes com instruções específicas e selecione-os na conversa.

4. As conversas são armazenadas em data/studio.json no computador.

5. A integração MCP/ComfyUI é uma etapa futura: esta versão é um chat de IA, ainda não executa ferramentas MCP.

Privacidade e limites

O servidor escuta apenas em 127.0.0.1. Provedores remotos recebem suas mensagens. Não cole chaves em chats. O armazenamento local não é criptografado.
